Este repositório contém a minha jornada de aprendizado na linguagem Python, composta por uma trilha de 115 exercícios práticos baseados no curso de **Python 3** do Professor Gustavo Guanabara, do portal **Curso em Vídeo**.



## 📋 Descrição do Projeto

O objetivo deste projeto é consolidar fundamentos de programação, desde conceitos básicos de lógica até a estruturação de aplicações modulares com persistência de dados. O repositório reflete a evolução técnica, dividido em "Mundo 1, 2 e 3", organizado em tópicos como:
- Tratamento de exceções e erros.
- Modularização de código (utilização de pacotes).
- Manipulação de arquivos de texto (.txt).
- Formatação de dados no terminal com cores e tabelas.
- Fundamentalmente, o projeto é a consolidação aplicação prática, em forma de exercícios, de uma metodologia de aprendizado proporcionada pelo curso de Python do Prof. Guanabara em seu portal do Curso em Vídeo.
